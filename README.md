# Flight-operations-data-analysis

A Pandas-based data analysis project on flight operations, covering data loading, inspection, cleaning, selection, filtering, sorting, grouping, aggregation, data transformation, and key findings.

## Project Contents

* `Flight_Operations_Data_Analysis.ipynb` — Complete data analysis notebook
* `Flight_Operations_Dataset.csv` — Flight operations dataset

## Tools Used

* Python
* Pandas
* Visual Studio Code
* Jupyter Notebook

## Analysis Workflow

1. Loading and understanding the dataset
2. Inspecting structure and statistics
3. Data selection and filtering
4. Sorting records
5. Grouping and aggregation
6. Data transformation
7. Meaningful data analysis
8. Key observations and findings
